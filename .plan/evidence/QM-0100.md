### ADR-010 — binding, and the controller's mid-task correction

ADR-010 (Accepted) is binding on this task. The controller's initial brief said
the six rank-4 tensors must be *"refused, not flattened"* by `inspect`, and
required a test named `refuses_rank_four_attn_bias_rather_than_flattening`.
**That was wrong about the layer, and the controller corrected it mid-task.**
Reading ADR-010 directly:

* `q_source::TensorDescriptor::shape: Vec<u64>` — *"arbitrary rank already"*;
* *"the metadata layer is rank-agnostic and the block, tile, and layout layers
  are 2-D with a 3-D-shaped hole already cut"*;
* `rank >3   bindAxes() returns NotImplemented carrying GRID-007`.

So the ceiling lives at **axis binding**, not at ingestion. Making `inspect`
refuse these six would have contradicted ADR-010 rather than honouring it. The
implemented behaviour is therefore: **ingestion and `q inspect` list all six at
their true `[1, 1, 1024, 1024]` shape**, and the tests are named for the layers
they actually test.

**`bindAxes()` / `GRID-007` does not exist anywhere in this tree.** Searched the
whole repository (excluding `node_modules`, `.git`, `target`): the only hits are
in `.plan/` and `docs/decisions/`, never in code. It is owned by **`QM-0061`**
(`.plan/tasks/QM-0061-axis-binding/TASK.md`, destined for `spatial/axes.ts` per
`.plan/TARGET_ARCHITECTURE.md` line 80), with a rank-4 → `NotImplemented`
/`GRID-007` case also carried by **`QM-0040`** (LOD block planner).
`schemas/visualization/spatial-contract.json` and its
`axis_binding.max_implemented_rank` (`QM-0004`) do not exist yet either.

`QM-0100`'s declared `## Files Expected to Change` is `.gitignore` and
`crates/q-cli/src/main.rs`. **Implementing `bindAxes()` here would be
out-of-scope scope expansion, and putting ADR-010's refusal in the wrong layer
would be worse than not having it.** It is therefore *not* implemented here, and
is recorded in `.plan/PLAN_CHANGELOG.md` as a finding naming `QM-0061` and
`QM-0040` as the owners, with the new fact that a real artifact now exists to
test it against.

What *was* verified — the invariant that matters and that is testable today:

1. **Nothing flattens.** All 82 tensors survive ingestion; the six rank-4
   masks keep `[1, 1, 1024, 1024]`, `element_count() == 1_048_576`,
   `byte_length() == 4_194_304`. Not collapsed to `[1024, 1024]`, not to
   `[1, 1048576]`, not dropped.
2. **Rank-4 addressing uses the true shape.** Exact scalar reads match an
   independent Python read on both value *and* absolute byte offset at five
   indices, including the asymmetric causal-mask pair. A flattened or
   mis-strided read cannot reproduce that.
3. **Every 2-D consumer refuses with context** rather than reinterpreting.
   These are incidental rank-2 preconditions (`read_slice_2d`, `read_row`,
   `BlockExtent::clamped_to`, the NSIR selector), **not** ADR-010's designed
   axis-binding refusal, and the test doc comment says so explicitly so a later
   reader cannot mistake one for the other.
